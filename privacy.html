Privacy Policy

Last updated: September 11, 2026

Nexus Online IDE is a free browser-based code editor operated by Varun Ganti (an individual, not a registered company). Contact: varun.m.ganti@gmail.com. Website: eerielettuce3717.github.io. Hosting: GitHub Pages.

What we collect

  • Without an account: files stay in your browser (localStorage). We do not receive them unless a run feature below sends code to a runtime.
  • If you sign in: email, display name, photo URL, provider, and user ID from Google, GitHub, or email/password via Firebase Authentication.
  • Optional analytics (off until you accept): signed-in usage events (file name and language, not source) and code snapshots when you run code.
  • GitHub save: only if you authorize GitHub. We request the repo scope so we can list and write repositories you own, including private ones.

When code leaves your browser

  • Python runs in-browser via Pyodide files loaded from jsDelivr.
  • Java runs in-browser via CheerpJ (Leaning Technologies CDN).
  • Some compiled languages send the file you run to the Piston API (emkc.org).
  • HTML preview stays in a sandboxed iframe of your own files. There are no YouTube, social, or ad embeds.

Legal bases and your rights

Account features rely on performing a contract you request. Analytics and snapshots rely on consent. Security and legal requests may rely on legitimate interests or legal obligation. We do not sell personal information and do not run advertising or Google Analytics. California residents may request access, correction, or deletion. We honor Global Privacy Control by keeping analytics off. EEA/UK users may also contact a supervisory authority. Email deletion or access requests to varun.m.ganti@gmail.com. We will erase account data we store within thirty days, except where retention is required by law. Data is processed in the United States (Firebase, GitHub).

Children

The Service is not directed at children under 13. EEA/UK users under the local digital-consent age (often 16) should not create an account without a parent or guardian.

The in-app policy at /#/privacy matches this document.
