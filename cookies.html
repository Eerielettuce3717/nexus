Cookie Policy

Last updated: September 11, 2026

Nexus Online IDE, operated by Varun Ganti, does not set first-party advertising or analytics HTTP cookies. The editor uses localStorage and, if you sign in, Firebase Authentication storage. EU/UK rules treat similar technologies like cookies.

Do we need consent?

Essential storage (files, sign-in, tokens you chose to save) is required to provide the editor. We do not use a cookie wall for that. Optional analytics (signed-in usage events and code snapshots) is off until you accept in the app banner. A Global Privacy Control signal keeps analytics off.

Storage we set

  • pyide-workspace-v1 — editor files
  • pyide-gh-token — GitHub token in sessionStorage after you authorize GitHub (cleared when the tab closes)
  • nexus-piston-config-v1 — optional Piston API settings you paste
  • nexus-analytics-consent-v1 — your analytics choice
  • Firebase Auth storage — signed-in session

Third parties

Google, GitHub, jsDelivr, CheerpJ, and Piston/emkc.org may set cookies on their own domains when their features run. We do not embed advertising, YouTube, or social widgets. Change your choice with Cookie settings in the app footer, or clear this site's data in your browser.
